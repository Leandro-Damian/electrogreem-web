# Electrogreem Web

Sitio web institucional desarrollado para **Electrogreem S.R.L.**, empresa dedicada a la gestión y tratamiento responsable de **Residuos de Aparatos Eléctricos y Electrónicos (RAEE)**.

El proyecto tiene como objetivo presentar de forma clara los servicios de la empresa, su proceso de gestión de residuos electrónicos y su impacto ambiental.

---

## 📌 Características del proyecto

* Diseño **responsive** (mobile-first)
* Implementación de **modo claro y modo oscuro**
* Secciones informativas orientadas a comunicación institucional
* Maquetación optimizada para diferentes resoluciones:

  * 375px
  * 576px
  * 768px
  * 1024px
  * 1440px
* Organización del código utilizando una estructura clara de estilos CSS

---

## 🧩 Secciones del sitio

El sitio está dividido en las siguientes secciones principales:

* **Inicio / Navegación**
* **Quiénes somos**
* **Nuestros procesos**
* **Impacto ambiental**
* **Contacto**
* **Footer institucional**

Cada sección está diseñada para explicar de manera progresiva:

1. Qué hace la empresa
2. Cómo gestiona los residuos electrónicos
3. Qué impacto positivo genera

---

## ⚙️ Tecnologías utilizadas

* **HTML5**
* **CSS3**
* **JavaScript**

El proyecto se desarrolló sin frameworks para mantener un control completo sobre la estructura y el rendimiento del sitio.

---

## 🌱 Objetivo del proyecto

El sitio busca comunicar la importancia de la **gestión responsable de residuos electrónicos**, promoviendo prácticas sostenibles y el cumplimiento de la normativa ambiental vigente.
